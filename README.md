
# 🎓 Udemy Clone

A simple Udemy-inspired online learning platform created using **HTML and CSS**.

## ✨ Features

* 🔍 Course search bar
* 📚 Course categories
* 🎯 Recommended courses section
* 🖼️ Hero/banner section
* 🎨 Clean and modern UI
* 📱 Responsive layout

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📌 About the Project

This project was created as a frontend practice project to improve my skills in **HTML, CSS, webpage layouts, positioning, and styling**.

> This is a learning project inspired by Udemy's design and is not affiliated with Udemy.
